# v0.1.0 — developer preview

First independent community release of the DeepSeek Harness RunCase Adapter.

Included:

- managed recording through `@deepseek-ai/dsh-sdk-client@0.1.2-alpha.2`;
- RunCase Interchange `agent.run.v1` conversion and validation;
- local pre-write redaction and overwrite protection;
- partial-event retention for runtime exits and timeouts;
- Windows x64, Ubuntu x64, and Apple Silicon macOS hosted contract CI;
- deterministic example, mapping notes, limitations, checksum, and build provenance.

Evidence boundary: the release uses a keyless JSON-RPC stand-in in hosted CI. No production DeepSeek account, physical Mac, task-quality claim, or full Runtime Evolution Workbench port is included.

Capture and Run files use separate atomic create-if-absent commits. A forced process stop between them can leave a valid capture without a Run; this is recoverable partial evidence, not a completed conversion.
